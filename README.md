# Better Sunlit

**선릿 밸리(Sunlit Valley)** 모드팩을 위한 종합 기능·연출·편의성·최적화 애드온 모드입니다.  
**대상 환경**: `Minecraft 1.20.1` · `Forge 47.4` · `Stardew Fishing 3.7` (원본 *Society: Sunlit Valley 4.2.2* 포함)

> [!TIP]
> **[최신 릴리스 다운로드 (GitHub Releases)](https://github.com/mihile/better-sunlit/releases/latest)**  
> 하나의 릴리스 Assets에서 **서버용**, **일반 클라이언트용**, **클라이언트 전용판** 중 환경에 맞는 JAR을 골라 **받은 파일명 그대로 `mods` 폴더**에 넣으면 됩니다.

---

## 핵심: 부팅 시간 대폭 단축 (`sunlit-boot.jar` 설정 필수)

Better Sunlit에는 클라이언트와 전용 서버 모두의 초기 부팅·클래스 로딩·리소스 스캔 시간을 크게 줄여주는 부팅 에이전트(**`sunlit-boot.jar`**)가 내장되어 있습니다.  
일반 모드처럼 `mods` 폴더에 넣기만 해도 일반 최적화와 기능은 작동하지만, **부팅 가속 효과를 온전히 받으려면 JVM 인수(Flag) 설정이 반드시 필요합니다.**

> [!IMPORTANT]
> **반드시 순서대로 진행하세요! (`config/sunlit-boot.jar` 확인 → JVM Flag 추가)**
>
> 1. 먼저 Better Sunlit JAR을 `mods` 폴더에 넣고 **게임(또는 서버)을 한 번 실행**합니다.
> 2. 실행 후 `minecraft/config/` (서버는 `서버폴더/config/`) 안에 **`sunlit-boot.jar`** 파일이 자동 생성되었는지 확인합니다.
> 3. 파일이 있는 것을 확인한 뒤, 사용 중인 런처(또는 서버)의 **JVM 인수(Flag)**에 아래 문구를 추가합니다.
>
> ```text
> -javaagent:config/sunlit-boot.jar
> ```

> [!WARNING]
> - **`config/sunlit-boot.jar` 파일이 없는 상태에서 `-javaagent:config/sunlit-boot.jar`를 먼저 넣으면 게임/서버가 시작되지 않습니다.** 꼭 1회 실행 후 파일 생성을 확인한 다음 추가하세요.
> - Better Sunlit을 제거할 때는 추가했던 `-javaagent:config/sunlit-boot.jar` 인수도 함께 지워야 합니다.
> - 한 번 설정해 두면 이후 Better Sunlit이 업데이트될 때 `config/sunlit-boot.jar`도 자동으로 최신 버전으로 동기화됩니다. (Windows에서 파일이 잠겨 있어도 종료 직후 자동 교체)

<details>
<summary><b>런처·서버별 JVM 인수(Flag) 적용 방법 보기</b></summary>

#### Prism Launcher / MultiMC
1. 인스턴스 우클릭 → **편집(Edit)** → **설정(Settings)** → **Java** 탭 이동
2. **Java 인수(JVM arguments)** 체크박스를 켜고 아래 문구 추가:
   ```text
   -javaagent:config/sunlit-boot.jar
   ```
   *(예: 기존 인수가 있다면 공백으로 구분해 함께 입력 → `-javaagent:config/sunlit-boot.jar -XX:MetaspaceSize=512m`)*

#### CurseForge 앱
1. 모드팩 프로필 클릭 → 우측 상단 `⋮` → **프로필 옵션(Profile Options)**
2. **추가 인수(Additional Arguments)** 항목에 아래 문구 추가:
   ```text
   -javaagent:config/sunlit-boot.jar
   ```

#### 전용 서버 (Dedicated Server)
1. 서버를 1회 실행해 `config/sunlit-boot.jar` 생성 확인
2. 서버 루트 폴더의 **`user_jvm_args.txt`** 파일을 열고 아래 한 줄을 추가 후 저장:
   ```text
   -javaagent:config/sunlit-boot.jar
   ```

</details>

## 버전 선택 및 설치 방법

[최신 다운로드](https://github.com/mihile/better-sunlit/releases/latest)의 Assets에서 사용 환경에 맞는 파일 1개를 받아 `mods` 폴더에 넣으세요. 기존 Better Sunlit JAR이 있다면 게임/서버를 종료한 뒤 교체합니다.

| 파일명 | 설치 위치 | 용도 및 특징 |
| :--- | :--- | :--- |
| **`better-sunlit-server.jar`** | 전용 서버 `mods` | 멀티플레이 서버용. 해골 광산 엘리베이터, 리얼피싱·연못·가축 동기화, `/bettersunlit update`, 서버 부팅 최적화 제공 |
| **`better-sunlit-client.jar`** | 클라이언트 `mods` | Better Sunlit 서버 접속 및 싱글플레이용. 모든 연출·UI·최적화 + 인게임 자동 업데이트 지원 |
| **`better-sunlit-client-only.jar`** | 클라이언트 `mods` | 서버에 Better Sunlit이 없을 때 플레이어만 단독 사용하는 [클라이언트 전용판](https://github.com/mihile/better-sunlit/tree/client-only) *(인게임 자동 업데이트 미포함)* |

- 받은 파일 이름 그대로 설치하면 되며, 일반판의 인게임 업데이트와 서버 롤백도 설치된 파일명 그대로 교체합니다.
- 서버 자동 업데이트 후 문제가 생기면 서버를 종료하고 `.better-sunlit-update/backups/` 폴더의 이전 JAR로 복원할 수 있습니다.

## 명령어 사용법 (`/bettersunlit`)

모든 명령어는 `/bettersunlit` 하위로 통일되어 있으며, 서버·클라이언트 탭 자동완성이 함께 동작합니다.

| 명령어 | 적용 대상 | 설명 |
| :--- | :---: | :--- |
| `/bettersunlit` | 공통 | 현재 설정 요약 및 사용 가능한 하위 명령어 안내 |
| `/bettersunlit realfishing on` / `off` | 서버·싱글 | 리얼피싱 낚시 펄떡임 연출 켜기/끄기 *(기본값: `OFF`)* |
| `/bettersunlit realfishing <활발초> <약화초> <간격초>` | 서버·싱글 | 펄떡임 활발 시간·약해지는 시간·단계 간격 설정 *(예: `3 4 1`)* |
| `/bettersunlit fishpond adaptive [배율]` | 클라이언트 | 물고기 연못 수중 표시를 개체 수/크기 자동 축소 모드로 설정 *(배율 `0.3`~`1.2`, 기본 `0.7`)* |
| `/bettersunlit fishpond swim` / `off` | 클라이언트 | 물고기 연못 수중 표시를 원본 크기 유영(`swim`) 또는 끄기(`off`)로 전환 |
| `/bettersunlit optimize <on\|off\|toggle>` | 클라이언트 | 접속 초반 청크 로딩 억제(업로드 페이싱·틱 제한) 즉시 켜기/끄기 *(기본값: `ON`)* |
| `/bettersunlit update` | 전용 서버 (OP/콘솔) | 최신 서버 JAR 다운로드·서명 검증 후 안전 종료 및 자동 교체·재시작 |

## 탑재된 기능 상세

<details>
<summary><b>특수 UI 및 게임플레이 연출</b> — 리얼피싱, 물고기 연못, 해골 광산 엘리베이터, 가축 아이콘, 새벽 스프링클러, 전용 메뉴</summary>

### 리얼피싱 (RealFishing)
- 낚아올린 물고기를 실제 보상 아이템과 연결된 3D 모델로 렌더링하며, 머리부터 꼬리까지 몸이 휘며 물가/땅 위에서 부드럽게 펄떡이는 연출을 제공합니다.
- 서버 홉 타이밍 동기화, 지상 이동 스킵 해제, 클라이언트 단조 클럭 및 위치 패킷 스냅 감쇠(`SnapDampener`)를 적용해 멀티플레이에서도 끊김 없이 부드럽게 움직입니다.
- 활발하게 펄떡이다가 서서히 약해지고 멈추며, 약해지기 시작하는 시점부터 회수할 수 있습니다. (초반 자석 모드 강제 흡입 방지 포함, 별 등급·수량·보상 NBT 보존)
- 바닐라/모드 엔티티 모델이 없는 **금붕어·넵튜나·거머리**는 전용 3D 모델과 텍스처로 표시되며, Stardew Fishing 미니게임을 끈 일반 낚시 보상에도 동일하게 적용됩니다.
- 설정은 `config/sunlit-fishing-visuals.json`에 저장됩니다.

### 물고기 연못 수중 표시 (`society:fish_pond`)
- 물고기 연못에 넣은 물고기들이 뒤쪽 3×4 물(또는 용암) 영역 안에서 실제 개체 수만큼 클라이언트 전용 모델로 헤엄칩니다.
- 실제 물고기처럼 잔잔히 머물거나 직선 활공 후 빠르게 방향을 꺾고, 벽 앞에서 쉬거나 벽을 따라 이동하며, 머리/몸통 회전을 분리해 **Fresh Animations** 유영 애니메이션과 자연스럽게 연동됩니다.
- 마릿수가 많거나 대형 어종일 때 자동으로 크기를 조절(`adaptive`, 기본 배율 `0.7`)합니다.

### 해골 광산 엘리베이터 및 층수 HUD (`society:skull_cavern`)
- 각 해골 광산 입구마다 독립된 엘리베이터 데이터를 관리합니다.
- 10층 단위 층 도달 또는 구리 던전(시련의 회당) 발견 시 토스트 알림과 함께 해당 위치와 지상 입구에 파괴 보호 엘리베이터 기둥(자석석 + 랜턴)이 자동 설치됩니다.
- 엘리베이터 우클릭 시 해당 광산에서 실제 개척된 정거장 목록이 최초 개척/발견자 이름과 함께 표시되어 즉시 이동할 수 있으며, 광산 내부 좌측 상단에 현재 층수와 구역이 표시됩니다.

### 가축 도구 쿨타임 및 상태 아이콘
- **우유 들통·마법 가위·유리병**을 들고 가축을 바라보면 머리 위에 수확 가능 상태 아이콘이 표시됩니다.
- 하루 주기는 낮/밤 기준 절반씩, 이틀 주기는 ¼씩 아래부터 색이 차오르며, 유리병의 이코르 채취도 자체 타이머 기준으로 진행 상태를 표시합니다. 배고픔과 호감도 부족 상태도 색상으로 구분됩니다.

### 새벽 스프링클러 연출
- 아침에 농지에 물을 주는 스프링클러에서 물방울이 회전하며 퍼지는 시각 효과를 추가하고, 가까운 여러 대가 동시에 작동할 때 분사음을 모아 깔끔하게 재생합니다.

### Better Sunlit 전용 화면 (메인 메뉴)
- 메인 메뉴의 **Better Sunlit** 버튼에서 현재 설치 버전과 버전별 변경 내역을 항목별로 펼쳐 확인할 수 있습니다.
- 업데이트 자동 확인·팝업 자동 열기 설정과 다운로드를 같은 화면에서 처리하며, 네트워크 조회에 실패해도 설치된 버전의 변경 내역을 열람할 수 있습니다.

</details>

<details>
<summary><b>편의성·업데이트·호환성 및 버그 수정</b> — 자동 업데이트, EMI/JEI 안내, 한글 입력, 모델·크래시 호환</summary>

### 클라이언트 자동 업데이트
- 자동 확인을 켜면 게임 실행 중에도 1분마다 새 서명 버전을 확인합니다.
- 메인 메뉴 Better Sunlit 버튼 모서리에 뛰는 빨간 느낌표가 표시되며, 사용자가 직접 선택한 업데이트만 내려받아 게임 종료 후 안전하게 교체합니다. (팝업 자동 열기는 기본 `OFF`)

### 전용 서버 업데이트 및 복구
- 전용 서버에서 새 서명 업데이트가 감지되면 OP 플레이어 접속 시 재시작 안내와 함께 알림을 표시합니다.
- OP 또는 서버 콘솔에서 `/bettersunlit update`를 실행하면 새 JAR을 내려받아 서명을 검증하고 서버를 안전 종료한 뒤 파일을 교체합니다. 선릿밸리 서버팩에서 `start.bat` + `RESTART=true`를 사용하면 자동으로 재시작됩니다.

### EMI 레시피·사용처 및 특수 조합법 지원
- 사용·염색 등으로 NBT 데이터가 붙은 배낭·보관함, 독 대나무 가시, 양조 플라스크도 대응하는 레시피와 사용처를 정상 조회합니다.
- 배낭·보관함의 특수 조합법도 실제 재료와 배치를 확인해 EMI의 `+` 버튼으로 조합대를 채울 수 있습니다.

### 낚시 조건 및 자연 식물 서식지 안내 (JEI / EMI)
- 물고기별 낚시 계절·지역·확률과 자연 식물의 서식 바이옴 정보를 JEI/EMI에서 바로 확인할 수 있습니다. (안내 스크립트와 번역 문구가 JAR에 내장되며, 같은 이름의 로컬 KubeJS 스크립트가 있으면 로컬 파일을 우선 사용)

### 모드 입력창 한글 조합 (Caramel Chat 연동)
- 비디오 설정 검색, Create 클립보드, 그림·사진 입력창, Supplementaries 텍스트 입력 등 지원되는 모드 입력창에서 한글 조합 입력이 자연스럽게 동작하도록 연결합니다.

### 풍선 보상 표시 거리 보완
- 서버 시뮬레이션 거리를 기준으로 풍선을 추적하고, 추적 중인 풍선이 클라이언트의 기본 개체 표시 거리 제한 때문에 일찍 사라지지 않도록 보완합니다.

### 모드 간 모델·렌더링·안정성 호환 수정
- **Carry On + Fresh Animations**: 생물을 들었을 때 렌더링 모델과 위치·회전 보간을 유지해 머리와 몸이 떨리는 현상을 완화합니다.
- **Rotten Creatures / Snow Pig / 대각선 담장**: 지원 몹의 모델·애니메이션 연결과 스노우 피그, 조약돌·화강암·모드 담장의 원본 재질 표시를 보정합니다.
- **엔티티 동기화 및 크래시 수정**: 늑대·고양이·광산 수레의 상태 동기화 순서를 맞추고, 메인 메뉴 파노라마 로딩 중 체크무늬 번쩍임, 게임 시작 중 렌더러 등록 경합 종료, 셰이더 사용 중 다중 레이어 아이템(예: 넵튜늄 낚싯대) 툴팁 크래시를 수정했습니다.

</details>

<summary><b>부팅·로딩 및 첫 접속 최적화</b> — 클라이언트·전용 서버 부팅 단축, 리소스·셰이더 캐시, 첫 접속 렉 완화</summary>

### 부팅 에이전트(`sunlit-boot.jar`) 및 서버·클라이언트 시작 가속
- 시작 단계의 클래스·ZIP 리소스 중복 읽기를 줄이고, 선택된 Mixin 클래스를 모듈별로 선로딩하며 Forge의 모드 의존성 순서와 로딩 스레드 설정을 준수합니다.
- **전용 서버 부팅 최적화**: 서버 시작 시 버려지는 충돌 보고서 하드웨어 사전 조회 생략, 블록 상태 정의, KubeJS 리소스팩·태그 정리, Farmer's Delight 도구 재료, LootJS·AdvancedLootInfo 루트 테이블 처리 경로를 최적화해 서버 부팅 및 준비 시간을 크게 단축합니다.

### 모델 베이크·EMF 병렬 처리
- 일반 모델과 지원되는 EMF 모델을 미리 준비·병렬 처리하고, 검증된 EMF(3.2.4 / 3.3.12) 구성에서는 애니메이션 검증 상태를 작업 스레드별로 분리해 잠금 대기를 줄입니다.
- Create·Puzzles Lib·Refined Storage 모델 준비, Forge 레이어 정의, 지연 모델 저장소, 배낭 블록 모양 계산의 중복 작업과 경합을 줄입니다.

### 텍스처·투명도·밉맵 및 셰이더 디스크 캐시
- 텍스처 읽기, Embeddium/Iris 기준 픽셀 투명도 검사, 스프라이트 밉맵 생성을 가속합니다.
- Iris·Colorwheel의 셰이더 준비·변환을 보완하고 GLSL 변환 결과를 디스크 캐시에 보관하며, 준비가 끝난 파서 캐시와 임시 메모리를 정리합니다.

### 리소스팩·KubeJS·언어·글꼴·레지스트리
- 리소스팩 경로 색인과 ZIP/경로 조회, KubeJS 스크립트·생성 리소스 처리, 언어 파일 병합, 글꼴·코드포인트·OBJ 문자열 처리의 반복 탐색과 할당을 줄입니다.
- 레지스트리·ObjectHolder·반사 조회 및 일부 모드의 버전·웹·인증서·이모지·지도 테마·미디어 이미지 초기화 병목을 완화합니다.

### 첫 월드 진입·멀티 접속 직후 렉 완화
- JEI 아이템 후보·UID 조회(임시 `ItemStack` 생성 축소), Create 석재 절단 레시피 비교, Every Compat 크리에이티브 탭 스택 변환, 렌더 섹션 인덱스 초기 용량 확보로 첫 진입 스파이크를 줄입니다.
- 접속 직후 청크 업로드 페이싱·스케줄링 백프레셔·틱 제한을 적용하며, 로딩이 억제되는 느낌이 싫다면 인게임에서 `/bettersunlit optimize off`로 즉시 해제할 수 있습니다. (`config/sunlit-client-perf.json`에 저장)

- EMF(원본 팩 3.2.4 및 최신 3.3.12 모두 지원)의 모델 파트·큐브 처리, 고속 변수 맵(`FastEmfVarMap`), 애니메이션 변수 조회, LOD 판정의 반복 비용을 줄입니다.
- GeckoLib 및 Longwings 나비·나방·포획망·아이템 모델의 변종 조회와 렌더링 부담을 완화합니다.

### 날씨·바람·계절 색상 및 환경음
- Particle Rain 입자와 바닐라 날씨 렌더링에서 설정·바이옴 조회를 재사용하고, 계절별 잎·풀 색상·바람 계산과 Ambient Sounds 바이옴/공기 영역 검사의 중복 조회를 줄입니다.

### 청크·블록·충돌 모양
- 청크 메시 생성 중 팔레트·블록 정보 조회와 가림 판정, `VoxelShape` 충돌 모양 합치기/최적화, 울타리·담장 모양 계산의 반복 연산을 줄입니다.

### 지도·글꼴·이모지·로그 및 보조 렌더링
- FTB Chunks 미니맵이 꺼져 있고 지도 모드가 없음이면 화면용 타일 업로드를 생략합니다. (저장·점유·강제 로딩 연동은 유지) JourneyMap 색상 변환과 작업 큐 비용도 줄입니다.
- 글꼴 조회, 이모지 후보 탐색, LogBegone 필터 정규식 처리, 텍스처 조회, Iris 차원 판정, 지원 환경의 Voxy 비동기 업로드 경로를 최적화합니다.

> 모든 최적화는 설치된 모드와 버전을 확인한 뒤 적용되며(일부 경로는 클래스 해시까지 검증), 대상 모드가 없거나 조건이 다르면 해당 경로만 안전하게 건너뜁니다. 실제 부팅 시간과 FPS 향상 폭은 하드웨어·리소스팩·셰이더·캐시 상태에 따라 달라집니다.
