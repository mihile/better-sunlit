# Better Sunlit

선릿 밸리를 위한 개인 기능·호환 모드입니다. Minecraft 1.20.1 / Forge 47.4 / Stardew Fishing 3.7에서 사용합니다.

소스와 업데이트는 이 저장소의 **[client](https://github.com/mihile/better-sunlit/tree/client)** · **[server](https://github.com/mihile/better-sunlit/tree/server)** 브랜치로 나눕니다. 각 환경은 자기 브랜치의 서명된 업데이트만 받습니다. 두 JAR을 같은 환경에 동시에 넣지 않습니다.

## 프레임 최적화

<details>
<summary>플레이 중 반복 계산과 렌더링 비용 줄이기</summary>

### 셰이더와 반투명 정렬
Oculus의 uniform·sampler 목록 순회에서 매 프레임 만드는 임시 객체를 줄이고, 사용한 sampler 범위만 정리합니다. Embeddium의 큰 정점 목록은 안정적인 기수 정렬로 처리하고, 반투명 그래프 정렬의 작업 배열을 재사용해 정렬과 메모리 할당 부담을 줄입니다.

### 몹 모델과 애니메이션
EMF의 모델 파트·큐브 처리와 애니메이션 변수 조회, LOD 판정에서 반복 작업을 줄입니다. Longwings의 나비·나방과 포획망·아이템 모델도 변종 조회와 모델 처리 비용을 줄입니다.

### 비·눈·바람과 계절 색상
Particle Rain의 날씨 입자와 바닐라 날씨 렌더링에서 설정·바이옴 조회를 재사용합니다. 계절별 잎·풀 색상과 바람 계산, Ambient Sounds의 바이옴·공기 영역 검사에서도 같은 값을 반복해서 찾는 비용을 줄입니다.

### 청크와 블록 처리
청크 메시 생성 중 팔레트·블록 정보 조회와 가림 판정의 반복 작업을 줄입니다. 충돌 모양 합치기·최적화, 울타리형 블록과 담장 모양 계산에서도 중복 작업을 줄여 블록 처리 부담을 완화합니다.

### 지도와 보조 화면
FTB Chunks 미니맵이 꺼져 있고 지도 모드가 없음이면 화면용 타일 업로드를 생략합니다. 지도 저장과 점유·강제 로딩 연동은 계속 처리합니다. JourneyMap 이미지 색상 변환과 관련 작업 큐의 반복 비용도 줄입니다.

### 글꼴·이모지·로그
글꼴 조회와 이모지 후보 탐색·문자열 처리 결과를 재사용하고, 이모지 목록 변경 시 캐시를 갱신합니다. LogBegone의 필터 준비와 정규식 처리에서도 불필요한 객체 생성을 줄입니다.

### 렌더링 보조 작업
텍스처 조회와 배치 버퍼 처리, Iris 차원 판정 등 렌더링 보조 경로의 중복 작업을 줄입니다. Voxy가 설치된 지원 환경에서는 비동기 업로드 경로도 보완합니다.

</details>

## 로딩 시간 최적화

<details>
<summary>게임 부팅·리소스 로딩·첫 월드 진입 빠르게 하기</summary>

### 부팅 에이전트와 Mixin 준비
`sunlit-boot.jar`가 시작 단계의 클래스·ZIP 리소스 조회에서 중복 읽기를 줄입니다. 선택된 Mixin 클래스를 모듈별로 미리 읽어 준비 단계의 대기를 줄이고, Forge의 모드 의존성 순서와 설정된 로딩 스레드 수를 따릅니다. 에이전트 사용에는 JVM 인수 설정이 필요하며, 설치된 에이전트는 Better Sunlit 업데이트와 함께 동기화됩니다.

### 모델 베이크와 EMF 애니메이션 검증
일반 모델과 지원되는 EMF 모델을 미리 준비하고 병렬 처리합니다. 검증된 EMF 구성에서는 애니메이션 검증 상태를 작업 스레드별로 분리해 잠금 대기를 줄입니다. ETF·EMF 버전과 동시성 보완 적용 여부를 확인한 뒤 대응 경로를 선택합니다.

### 모드별 모델과 블록 모양 준비
Create·Puzzles Lib·Refined Storage의 모델 준비, Forge 레이어 정의와 지연 모델 저장소의 중복 작업을 줄입니다. 배낭 블록 모양은 중복 상태를 먼저 정리한 뒤 계산해 시작 중 모델 로딩 경합을 줄입니다.

### 텍스처 읽기·투명도 검사·밉맵
텍스처 읽기와 픽셀 투명도 검사, 밉맵 생성에서 반복 픽셀 접근과 계산을 줄입니다. 설치된 Minecraft·렌더러·Iris의 검토된 구현에 맞는 빠른 경로를 선택합니다.

### 셰이더 읽기·변환·캐시
Iris와 Colorwheel의 셰이더 준비·변환을 보완하고 GLSL 변환 결과를 디스크 캐시에 보관합니다. 큰 셰이더 문자열의 캐시 키는 제한된 버퍼로 계산해 임시 메모리를 줄이며, 준비가 끝난 파서 캐시도 정리합니다. 블록 재질 매핑의 초기 용량과 정수 속성 이름 재사용으로 테이블 확장·문자열 생성 비용을 줄입니다.

### 리소스팩·언어·글꼴
리소스팩 경로 색인과 ZIP·경로 조회, KubeJS 생성 리소스 처리를 보완합니다. 언어 파일 병합과 글꼴·코드포인트·OBJ 모델 문자열 처리에서도 반복 탐색과 임시 객체 생성을 줄입니다.

### 레지스트리·스크립트·시작 보조 작업
블록 상태 정의, 레지스트리·ObjectHolder·반사 조회, KubeJS 스크립트 읽기의 반복 작업을 줄입니다. 시작 중 버려지는 충돌 보고서의 하드웨어 사전 조회를 생략하고, 일부 모드의 버전·웹·인증서 준비 경로와 이모지·지도 테마·미디어 이미지 초기화도 보완합니다.

### 첫 접속 시 JEI·Create·Every Compat
JEI 아이템 후보 생성 중 같은 후보 목록을 제한된 범위에서 재사용하고, 일반 아이템 식별자를 구할 때 임시 ItemStack 생성을 줄입니다. Create 석재 절단 레시피는 비교 후보를 좁히고 그룹별 재료 목록을 재사용합니다. Every Compat은 현재 크리에이티브 탭에 보낼 아이템만 스택으로 변환합니다.

### 첫 청크 등록과 초기 캐시
시야 거리·월드 높이에 맞춰 렌더 섹션 인덱스의 초기 용량을 준비하고 JEI 초기 캐시 용량을 조정해, 첫 접속 중 자료구조를 여러 번 확장하는 비용을 줄입니다.

최적화 적용 여부는 설치된 모드와 버전에 따라 달라집니다. 일부 경로는 검토된 클래스의 해시까지 확인하며, 해당 모드가 없거나 지원 조건이 맞지 않으면 그 경로를 건너뜁니다. 실제 부팅 시간과 프레임은 하드웨어·리소스팩·셰이더·캐시 상태에 따라 달라집니다.

</details>

## 편의성

<details>
<summary>업데이트·아이템 조회·입력과 표시 개선</summary>

### 클라이언트 업데이트
자동 확인을 켜면 시작 후 실행 중에도 1분마다 새 버전을 조회합니다. 메인 메뉴 Better Sunlit 버튼의 뛰는 빨간 느낌표를 눌러 변경 내역과 업데이트를 확인하고, 선택한 파일은 게임 종료 후 교체합니다. 팝업 자동 열기는 기본 OFF이며 화면에서 켤 수 있습니다.

### 서버 업데이트와 복구
서버 시작 전에 서버 채널의 서명된 업데이트를 확인합니다. 새 버전의 정상 시작이 확인되지 않으면 다음 실행에서 백업을 복원하고 해당 버전의 재설치를 막습니다.

### EMI 레시피와 사용처 조회
사용·염색 등으로 데이터가 붙은 배낭과 보관함, 독 대나무 가시·양조 플라스크도 대응하는 레시피와 사용처를 조회합니다. 배낭·보관함의 특수 조합법은 실제 재료와 배치를 확인해 EMI의 + 버튼으로 조합대를 채웁니다.

### 낚시 조건과 자연 식물 서식지 조회
낚시의 계절·지역·확률과 자연 식물의 서식 바이옴을 JEI/EMI에서 확인합니다. 안내 스크립트와 표시 문구를 JAR에 포함하며, 같은 이름의 로컬 KubeJS 스크립트가 있으면 해당 파일을 사용합니다.

### 모드 입력창 한글 조합
Caramel Chat을 통해 비디오 설정 검색, Create 클립보드, 그림·사진 관련 입력창과 Supplementaries 텍스트 입력 등 지원되는 모드 입력창의 한글 조합을 연결합니다.

### 풍선 보상 표시 거리
서버의 시뮬레이션 거리를 기준으로 풍선을 추적하고, 추적 중인 풍선이 클라이언트의 기본 개체 거리 제한 때문에 일찍 사라지지 않도록 보완합니다.

### 모델·화면·상태 표시 호환
Carry On으로 든 생물의 위치·회전 보간과 모델을 유지해 Fresh Animations의 떨림을 줄입니다. Rotten Creatures의 지원 몹은 몸·팔다리 위치와 애니메이션 연결을 보정합니다. 늑대·고양이·광산 수레의 상태 동기화 순서를 맞추고, 메인 메뉴 파노라마 준비 중 체크무늬가 번쩍이는 현상도 보완합니다.

</details>

## 추가된 특수 UI 및 기능

<details>
<summary>가축 상태 아이콘·낚시 연출·스프링클러와 Better Sunlit 화면</summary>

### 가축 도구 쿨타임과 상태 아이콘
우유 들통·마법 가위·유리병을 들고 가축을 보면 머리 위에 수확물 아이콘이 표시됩니다. 하루 주기는 낮과 밤으로 나눠 절반씩, 이틀 주기는 같은 경계에서 ¼씩 아래부터 색을 채웁니다. 유리병의 이코르 표시는 자체 타이머를 기준으로 절반씩 채웁니다. 배고픔과 호감도 부족 상태도 색으로 구분합니다.

### 리얼피싱
낚은 물고기를 원래 보상 아이템과 연결된 모델로 표시하고, 머리부터 꼬리까지 몸이 휘는 펄떡임을 추가합니다. 활발하게 움직이다가 약해지고 멈추며, 약해지기 시작하면 회수할 수 있습니다. 별 등급·수량·보상 NBT를 보존합니다.

기본값은 OFF입니다. `/bettersunlit realfishing on`·`/bettersunlit realfishing off`로 전환하고 `/bettersunlit realfishing 3 4 1`로 활발한 시간·약해지는 시간·간격을 초 단위로 정합니다. 기존에 저장한 켜짐·꺼짐과 시간 설정은 이어집니다. 원래 엔티티 모델이 없는 금붕어·넵튜나·거머리는 전용 모델과 텍스처로 표시하며, 그 외 모델이 매칭되지 않는 보상은 일반 아이템으로 처리합니다. 미니게임을 건너뛴 낚시 보상에도 같은 적용 조건을 사용합니다.

### 물고기 연못 수중 표시
물고기 연못(`society:fish_pond`)에 물고기를 넣으면 뒤쪽 3×4 물(또는 용암) 영역 안에서 실제 개체 수만큼 물고기들이 헤엄치는 모습을 클라이언트 전용 모델로 표시합니다. 마릿수가 늘어나거나 대형 어종일 때 자동으로 크기를 조절(기본 최소 배율 `0.7`)하며, `/bettersunlit fishpond adaptive 0.8`처럼 축소 배율(`0.3`~`1.2`)을 정하거나 `/bettersunlit fishpond <adaptive|swim|off>`로 유영 방식을 바꿀 수 있습니다.

### 해골 광산 엘리베이터 및 층수 표시
각 해골 광산(`society:skull_cavern`) 입구마다 독립된 엘리베이터를 관리합니다. 10층 단위 층에 도달하거나 구리 던전(시련의 회당)을 발견하면 토스트 알림과 함께 해당 위치와 지상 입구에 파괴 보호 엘리베이터 기둥(자석석 + 랜턴)이 자동 설치됩니다. 엘리베이터를 우클릭하면 그 광산에서 실제로 개척된 정거장만 최초 개척/발견자 이름과 함께 표시되어 이동할 수 있으며, 광산 내부 좌측 상단에 현재 층수와 구역이 표시됩니다.

### 새벽 스프링클러 연출
아침에 농지에 물을 주는 스프링클러에서 물방울이 회전하며 퍼집니다. 가까운 여러 대가 동시에 작동할 때 분사음을 모아 재생합니다.

### Better Sunlit 전용 화면
메인 메뉴 버튼에서 설치 버전과 버전별 변경 내역을 확인하고, 항목을 펼쳐 자세한 내용을 읽을 수 있습니다. 업데이트 자동 확인·팝업 설정과 다운로드도 같은 화면에서 처리하며, 조회에 실패해도 설치된 버전의 변경 내역을 볼 수 있습니다.

</details>

## 설치

- **클라이언트**는 [최신 클라이언트 릴리스](https://github.com/mihile/better-sunlit/releases/latest)에서 `better-sunlit.jar`을 받습니다.
- **전용 서버**는 [서버 릴리스 목록](https://github.com/mihile/better-sunlit/releases?q=server-build-&expanded=true)에서 최신 `server-build-*`의 `better-sunlit.jar`을 받습니다.
- 각 릴리스의 `SHA256SUMS.txt`에서 다운로드 파일의 해시를 확인할 수 있습니다. 기존 `sunlit-fishing-visuals-*.jar`은 게임 종료 후 별도 보관하고 `mods`에는 한 버전만 둡니다.

Minecraft와 선릿밸리의 비공식 애드온입니다. 이 저장소에는 애드온만 있으며, 필요한 게임·모드팩·의존 모드는 각 공식 배포처에서 설치합니다. 클라이언트는 자동 업데이트 확인을 끌 수 있고, 다운로드와 교체는 사용자가 선택합니다.

낚시 연출을 보려면 서버와 클라이언트 양쪽에 설치합니다. 네트워크 프로토콜은 기존 1.2.4와 같은 `3`을 유지합니다. 기존 설정·데이터를 보존하기 위해 Forge mod ID `sunlit_fish_visuals`를 유지하며 표시 이름과 배포 파일 이름은 Better Sunlit입니다.

서버 업데이트는 배포 소스의 `scripts/Update-Server.ps1`을 서버의 `tools/better-sunlit/`에 두고, 시작 BAT에서 Minecraft 실행 전에 호출합니다. 서명 검증 키는 JAR에 포함되고 개인 서명 키는 배포하지 않습니다.
